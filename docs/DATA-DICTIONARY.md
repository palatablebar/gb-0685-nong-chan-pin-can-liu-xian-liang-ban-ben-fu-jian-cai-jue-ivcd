# 检测区间与复检

采样日期选择限量标准[start,end)，不使用报告出具日。同产品同残留项目在采样日须恰有一条有效标准，方法须在适用范围内。浓度统一mg/kg，ug/kg与ppb乘0.001，ppm等于mg/kg。检出限LOD必须大于0。

定量值以[value,value]记录，低于LOD的定量值拒绝。ND或<LOD以[0,LOD)记录，<后的数值必须等于报告LOD。区间上界≤限量为PASS，下界>限量为FAIL，其余UNCERTAIN。<0.01相对0.005限量为不确定，不能当零。

复检relation指向原报告，必须同样本、同批次、同产品、同残留项目、同方法、同采样日，报告日严格更晚。引用环、悬空引用与异样本引用隔离。每样本/项目只允许一个原始报告根。有效复检按reported、version取最新；并列结果矛盾拒绝。其他残留项目不因复检被覆盖。批次按FAIL>UNCERTAIN>PASS取最高风险等级。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同一报告ID的多个版本先选最高version，再构建复检引用链；历史版本留作采信证据，不重复参与最终项目判定。

## 复检保存与温控裁决

复检到达时样本可能已超过常规保存期。复检受理前须核对保存记录与冷链温度记录，形成“受理 / 不受理”裁决，该裁决是项目判定、批次级别与封存资格的共同依据（同一 `basis_id`）。

保存记录字段：`sample_id`、`batch`、`storage_start`、`storage_end`、`condition`（冷藏 / 冷冻 / 阴凉）。温控记录字段：`record_id`、`sample_id`、`batch`、`start`、`end`、`temp_c`。时间须带偏移并转UTC，温度用 Decimal。证据来源为运行参数 `storage` / `coldchain`；内置样例（dirty/clean/legacy.csv）由系统附带演示证据，其他来源未提供证据时按证据不足处理。

裁决规则：

- 同一 `(sample_id,batch)` 保存记录须恰好一条，温控记录覆盖整个保存窗口且无缺口；保存条件须为已知值。
- 保存时长 ≤ 常规保存期（24h）为 regular；>24h 且 ≤72h 为 conditional（条件受理）；>72h 判 `RETENTION` 不受理。
- 温控在 [2,8]℃ 之外累计升温超过 30 分钟，或任一读数超过硬上限 10℃，判 `COLDCHAIN` 不受理。
- 证据缺失、缺口、时间/温度非法、保存条件未知判 `EVIDENCE` 不受理。

不受理或处理中断时，该复检行隔离（`EVIDENCE`/`COLDCHAIN`/`RETENTION`），原始报告恢复参与选版，即恢复旧版结论；不因失活样本推翻原判定，也不因个别复检拒绝而拖住整批出证。仅当证据账自身不平或顶层裁决中断时，封存资格才置为待复核。

证据账：输入保存/温控记录数 = 已使用 + 未使用（隔离）。原始保存与温控记录随归档证据文件保全，任何路径（含处理中断）不得丢失记录。同一复检重跑按 `id` 去重，只产生一条裁决，`basis_id` 稳定。

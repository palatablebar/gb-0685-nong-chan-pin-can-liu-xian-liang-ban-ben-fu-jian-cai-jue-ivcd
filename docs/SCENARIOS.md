# 检测场景

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

复检在出证前到达，样本自采样至复检约46小时，已超过常规保存期。内置样例附带保存与温控证据：冷链仅采样后10小时短时升温15分钟至9.2℃。裁决为条件受理，12条复检全部采纳，项目判定、批次判级与封存资格共用同一 `basis_id`。若改用其他来源且未提供保存/温控证据，则12条复检按证据不足隔离并恢复初检 UNCERTAIN 结论，原报告与原始温控记录完整保全，批次仍可出证。
